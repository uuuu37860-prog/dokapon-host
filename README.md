# Dokapon Host — ขั้นที่ 1: แอปรันเกมแบบเนทีฟ (ยังไม่สตรีม)

เป้าหมายขั้นนี้คือทดสอบว่า build ผ่านไหม และเกมวิ่งเต็มสปีดบนมือถือคุณหรือเปล่า
ผู้จัดทำยังไม่ได้คอมไพล์แอปนี้เลย (ไม่มีเครื่องมือ Android ในที่ที่เขียนโค้ด) ถ้า build พัง ส่งข้อความ error มาแก้ได้

## ขั้นตอน (ทำจากมือถือทั้งหมด)
1. สร้าง repo ใหม่บน GitHub ชื่อ `dokapon-host`
2. Add file → Upload files เลือก 8 ไฟล์นี้ (แตก zip ก่อน):
   `settings.gradle.kts` `build.gradle.kts` `gradle.properties` `app.build.gradle.kts`
   `AndroidManifest.xml` `MainActivity.kt` `GameActivity.kt` `README.md` → Commit
3. Add file → Create new file ตั้งชื่อ `.github/workflows/build-apk.yml`
   เปิดไฟล์ `build-apk.yml` จาก zip คัดลอกเนื้อหาทั้งหมดมาวาง → Commit (การ commit นี้สั่ง build อัตโนมัติ)
4. แท็บ Actions: รอ 5–10 นาทีจนขึ้นเครื่องหมายถูกสีเขียว
   ถ้าเป็นสีแดง กดเข้าไปดูขั้นที่แดง คัดลอกบรรทัด error ส่งมา
5. หน้าแรกของ repo มีหัวข้อ Releases ทางขวาหรือด้านล่าง กดเข้า build ล่าสุด แล้วโหลด `app-debug.apk`
6. ติดตั้ง (Android จะถามให้อนุญาตติดตั้งจาก Chrome และ Play Protect อาจเตือน เลือกติดตั้งต่อ)

## ใช้งาน
1. กด "เลือกไฟล์เกม" เลือกทั้ง `.cue` และ `.bin` พร้อมกัน หรือเลือก `.bin` อย่างเดียว (ต้องมีที่ว่างในเครื่องเท่าขนาดเกมอีกหนึ่งชุด)
2. ถ้ามี BIOS ให้เลือกด้วย (ไม่บังคับ)
3. กด "เริ่มเกม" เล่นด้วยปุ่มบนจอ
4. ถ้าปุ่ม ✕ กับ ○ ทำงานสลับกัน บอกผม จะแก้ค่า swapAB

## ขั้นต่อไป (ถ้าขั้นนี้ลื่น)
สตรีมภาพไปยังหน้าเว็บของเพื่อน (WebRTC) และรับปุ่มของเพื่อนเป็นผู้เล่น 2–4
ส่วนเสียงเกมทำทีหลังสุด
